# Pro forma SSA earnings samples

Fake names and SSNs. Upload these in the PIA Calculator the same way you would a file from ssa.gov.

| File | Use |
|---|---|
| `common_case_born_1966.xml` | Age-58+ career with 35+ years |
| `high_earner_taxable_max.xml` | High earner (cap-then-index check) |
| `career_with_gaps.xml` | Several zero years |
| `married_self_alex.xml` / `married_partner_riley.xml` | Married household, two uploads |
| `vintage_stale_2023.xml` | Old file + missing recent years → re-download copy |
| `vintage_fresh_posting_lag.xml` | Fresh file still missing last year → posting-lag copy |

Copies also live in `frontend/public/sample-earnings/` so they can be downloaded from the running app.
